頁面主題：遊戲介紹 > 將帥與傭兵

## 內容
- `傭兵與將帥.csv`：依朝鮮、日本、台灣、中國、印度整理傭兵與將帥名稱。
- `怪物與幻獸.csv`：依地區整理怪物、轉職怪物與幻獸。
- `gs_43707_data.json`：同一批資料的結構化 JSON，方便直接匯入網頁遊戲。
- `來源與整理說明.txt`：來源與整理規則。
