## 已確認的目前功能

- 單人網頁放置 RPG；主角加最多 11 名出戰傭兵，最多 12 人編隊。
- 三個角色存檔、共用倉庫、舊存檔遷移與安全載入。
- 漢陽村與四國城市、斜角城鎮地圖、NPC 對話、好感度、委託、商店、客棧與傭兵服務。
- 世界地圖、地圖解鎖、怪物圖鑑、一般怪與首領、多波遭遇、掉落、材料、裝備、寶石與合成。
- 即時戰鬥採 50ms 遊戲時脈；各角色依自己的攻速、MP、冷卻與自動技能行動。
- 戰鬥畫面已定案為「敵上我下」：敵軍／首領在上方，中央顯示技能與傷害效果，我方角色與血條在下方。
- 自動狩獵已完成：選擇怪物後會持續戰鬥、結算經驗與掉落、刷新下一波；全隊倒下時停止並回漢陽客棧療傷。
- 放置收益、商路、離線結算、商團領地、裝備強化／合成、任務主線與響應式 HUD 已存在。

## 關鍵戰鬥規則

- 我方前／中／後排位置影響戰鬥；前排有傷害加成，後排具即時戰鬥閃避規則。
- 一場副本最多 12 對 12；普通怪依出戰人數縮放遭遇上限。
- 怪物死亡後獎勵只結算一次；指定狩獵會保留目標並自動鎖定下一波。
- 全隊倒下或撤退會進入客棧療傷，療傷完成才可再出發。
- 白虎林／白虎類戰鬥在出戰傭兵超過 5 名時，敵方能力依既有規則提高。
