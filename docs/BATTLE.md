# 戰鬥系統

核心流程由 `app/game-battle-actions.ts`、`app/realtime-battle-engine.js`、`app/mercenary-realtime-battle.js`、`app/battle-arena.tsx` 與地下城模組處理；戰鬥視覺資料位於 `app/battle-visual-data.ts`。怪物資料位於 `data/monsters/`，技能資料位於 `data/skills/`。

## 戰鬥循環

選擇區域／敵人 → 建立戰鬥狀態 → 主角與傭兵行動 → 傷害／狀態更新 → 勝利或失敗 → 結算經驗、掉落與任務進度 → 回存遊戲狀態。

## 不可破壞規則

- 顯示用即時事件不得直接寫入 localStorage。
- 獎勵、經驗、擊殺數與任務進度每場結算一次；重載或連續點擊不得重複結算。
- 無效目標、死亡單位、空隊伍和戰鬥中斷都需有安全處理。
- 數值改動要同時考量普通戰鬥、地下城、技能與傭兵 AI。


## 戰鬥驗收

- [ ] 主角、傭兵、怪物與首領均可正常開始、結束與重試。
- [ ] HP／MP、死亡與復原、技能冷卻、自動技能與自動用藥正確。
- [ ] 勝負結算、掉落、經驗與任務目標只計算一次。
- [ ] 重新整理或載入舊存檔不會卡在無效戰鬥狀態。
- [ ] 以對應的 `tests/*battle*.test.mjs` 或新增測試覆蓋規則改動。
