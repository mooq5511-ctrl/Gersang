# 地圖與區域設計

地圖資料位於 `data/maps/gersang-world-map.ts`；畫面主要在 `app/isometric-world-map.tsx`、`app/classic-map-interface.tsx`，城鎮服務設定見 `app/town-map-config.ts`。

## 設計原則

- 區域、城鎮、傳送點、怪物與服務都使用穩定 ID。
- 地圖資料定義「可去哪裡」；UI 僅呈現與導向；戰鬥規則不應散落在地圖元件。
- 解鎖條件要能在資料與介面清楚說明，未解鎖時提供原因或下一步。
- 新區域至少指定怪物、獎勵方向、服務與進入／返回方式。

## 區域條目範本

```md
### 區域名稱
- ID：`region-id`
- 類型：城鎮／野外／地下城
- 進入條件：等級、任務或免費
- 可前往：
- 怪物與首領：
- 城鎮服務／NPC：
- 主要掉落與成長目的：
- 視覺主題與 BGM：
- 退出／失敗處理：
```

## 新地圖驗收

- [ ] 從相鄰區域可進入並可安全返回。
- [ ] 鎖定狀態、解鎖條件與提示一致。
- [ ] 怪物 ID、戰鬥背景、掉落與經驗來源正確。
- [ ] 重載後目前位置與選取目標不會造成壞存檔。
- [ ] 桌面及窄螢幕地圖文字、按鈕與點擊區域可用。
