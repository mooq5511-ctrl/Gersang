# 槍／弓兵種樹 V1（2026-10-03）

## 範圍

一個起點、二階選路、後續沿原路晉升；不新增更多分岔、不重建遊戲。朝鮮槍兵招募入口／原始穩定 ID 保留，避免任務依賴失效；一階成長名稱改為「新手槍兵」。不清除玩家傭兵、材料或裝備。

- 七／八階兵符來源尚未開放，顯示預覽；已有高階兵符仍可使用。沒有虛構高階關卡。
- 玩家入口：主角與隊伍 → 選傭兵 → 能力值 → 進階 → 查看能力。共同起點顯示槍／弓兩個按鈕與各自需求；選定後只显示原路線下一階按鈕。兩條完整路線保留預覽與目前位置。
- 槍線沿用原八階公式；弓線從二階起，在未取整共同基準上套用 ATK ×1.15、DEF ×0.70、HP ×0.75。階級倍率與複利不變；比例不是每次轉職重複乘一遍。所有數值只在最終取整。裝備與已分配屬性另外加成，不重置。
- 槍線沿用現有 `spear` 技能：突槍穿陣破甲、近戰普攻減傷與反騎獸；弓線透過新的轉職專用 `merchant-promotion-bow` 模板使用既有 `archer` 戰鬥技能：穿林重箭集火低血量敵人、獵獸被動與遠程攻擊。沒有把被封存的原弓手招募重新開放。
- 本版每條路沿用一組既有技能，尚未做八階各自的新技能／特效。兩條路線的站位、技能、基準能力與圖片已有實際差異，不只是改名稱。
- 首次選路設定槍線前排／弓線後排；之後晉升保留玩家調整的站位。轉職只校正 HP/MP 上限，不免費補滿血量。
- 弓線使用專案既有弓手戰鬥圖與成熟半寫實 `archer.jpg` 半身像；沒有假稱新增專屬立繪。

## 兵符與安全

- 二階：槍線消耗長槍兵符，弓線消耗新增長弓兵符。
- 三階：槍線消耗鐵騎兵符，弓線消耗新增強弓兵符。
- 四階以上仍共用精銳／修羅／御皇／天魔／軒轅將神兵符。
- 來源仍是前一輪已確認的真實怪物／關卡。普通怪二階兵符總掉率 3%，三階總掉率 2%；中符後以另一個外部抽樣等機率選擇槍或弓。因此二階各 1.5%，三階各 1%。Tooltip 明確標示合計與此符實際機率，同場最多一枚。
- 階級門檻、成功才消耗一枚、保留 XP、等級／裝備、戰鬥／派遣中禁止轉職與重複操作保護維持不變。已選路後拒絕跨線，失敗不扣符。
- 舊 `merchant-spear` 存檔直接視為槍線，已轉職階級不降階；弓線模板與新增材料／待領字段經由現有還原系統保存。新弓符不可賣，滿包待領後可取回。
