# 開發待辦

工作開始前將待辦切成可在一個 commit 內驗證的項目；完成後打勾並移至 `CHANGELOG.md` 或相應設計文件。

## 高優先

- [ ] 為現有 NPC 任務補上對話、條件、獎勵與重載測試。
- [ ] 檢查所有存檔正規化對新增欄位的預設值。
- [ ] 為主要戰鬥與地下城流程建立手動驗收清單。

## 中優先

- [ ] 整理地圖區域、解鎖條件、怪物與服務的對照資料。
- [ ] 補齊傭兵職業／升階／覺醒的 UI 說明與測試覆蓋。
- [ ] 記錄裝備、合成與掉落來源，方便平衡調整。

## 低優先

- [ ] 整理 placeholder 資產清單與替換順序。
- [ ] 建立常用手動測試存檔或重現步驟。

## 工作項目範本

```md
### [ ] 簡短目標
- 範圍：會碰到的資料、規則與 UI。
- 驗收：玩家做什麼、應看到什麼結果。
- 存檔：新增欄位／預設值／遷移，或「無影響」。
- 測試：自動測試檔與手動步驟。
- 預計 commit：feat|fix|art|balance|refactor|chore: 描述
```
