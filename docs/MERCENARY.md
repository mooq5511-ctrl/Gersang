# 傭兵系統

傭兵規則集中在 `app/mercenary-roster.ts`、`app/game-squad-actions.ts`、`app/mercenary-battle.ts`、`app/mercenary-promotion*.ts` 與 `data/mercenaries/`。`GameState.mercs`、`restingMercs`、`active` 與 `formation` 都屬存檔相容性範圍。

## 玩家循環

招募 → 查看職業與技能 → 上陣／編隊 → 戰鬥成長 → 休息或升階／覺醒 → 調整隊伍。

## 規則原則

- `uid` 是個體識別，`templateId` 是職業／原型識別；不可互相取代。
- 上陣名單與隊形位置需保持一致；無效或重複 ID 要安全正規化。
- 升階、覺醒與裝備變更後，數值與戰鬥快照應立即重算。
- 移除、休息或死亡不得遺失傭兵裝備、經驗或存檔資料。

## 驗收清單

- [ ] 招募後可在 roster 看見正確資料與成本變動。
- [ ] 上陣、休息、換位與隊伍上限均正確。
- [ ] 戰鬥傷害、死亡、經驗與升級會同步回存檔。
- [ ] 升階／覺醒前置條件與消耗不能被重複扣除或繞過。
- [ ] 新舊存檔、空隊伍與不存在的傭兵 ID 都能安全載入。
