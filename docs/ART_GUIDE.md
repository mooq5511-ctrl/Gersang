# 美術與素材指南

目標是維持具有巨商風格靈感、但屬於《Gersang》自身辨識的東亞商旅奇幻視覺。所有素材需有可追溯來源與使用權；不可假設外部遊戲資產可直接使用。

## 視覺方向

- 氣氛：商旅、城鎮市集、異聞與冒險；資訊層次優先於華麗特效。
- 地圖：易辨識的區域地標與路徑；城鎮服務要可快速辨識。
- 戰鬥：角色、敵人、目標與危險狀態在一眼內可區分。
- UI：深色底搭配有限的強調色；避免同時使用過多高飽和色。

## 檔案與來源

- 檔名小寫 `kebab-case`：`hanyang-apothecary-portrait.webp`、`tiger-king-attack.webp`。
- 動作或版本以明確後綴：`-idle`、`-attack`、`-hit`、`-v2`。
- 新素材記錄來源、作者／授權、原始檔位置、遊戲用途與替換狀態。
- 先使用專案 placeholder；未驗證授權的素材不得提交或發佈。

## 提交前檢查

- [ ] 素材路徑與資料引用一致，遺失時有合理 fallback。
- [ ] 檔名、尺寸、透明背景與裁切符合使用情境。
- [ ] UI 對比足夠，色盲或低亮度情境仍可辨識關鍵狀態。
- [ ] 動畫與特效不掩蓋傷害、技能結果或操作。
- [ ] 提交訊息使用 `art:`，並避免加入原始巨大檔、未授權檔或不必要的建置產物。
