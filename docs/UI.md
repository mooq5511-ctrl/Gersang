# UI 與體驗規範

主要遊戲 UI 在 `app/game-v15.tsx`，樣式集中於 `app/globals.css`、`app/classic-map-interface.css`、`app/battle-impact.css` 等模組。UI 需維持「資訊清楚、下一步明確、可在窄螢幕操作」。

## 原則

- 將視覺元件、資料與規則分離；UI 不直接成為唯一資料來源。
- 危險或不可逆操作需明確文字與確認；忙碌中操作要停用或防連點。
- 金錢、素材、生命、冷卻、鎖定條件等玩家決策資訊須可讀且更新一致。
- 保留繁中術語一致性；按鈕使用動詞，例如「招募」、「裝備」、「領取」。

## 新介面需求範本

```md
### 功能名稱
- 玩家目的：要完成什麼？
- 入口：地圖／NPC／按鈕／快捷列。
- 顯示資訊：
- 可執行動作與成功回饋：
- 空／載入／錯誤／鎖定狀態：
- 桌面與手機佈局：
- 鍵盤或無障礙需求：
- 驗收步驟：
```

## UI 檢查

- [ ] 主要操作有清楚標籤，不只依賴圖示或顏色。
- [ ] 長名稱、大數字、空背包與無傭兵狀態不破版。
- [ ] 彈窗可關閉，不遮住必要操作，焦點順序合理。
- [ ] 同一操作連點不會重複扣款、發獎或建立重複資料。
- [ ] 在窄螢幕寬度檢查文字、按鈕、捲動與戰鬥 HUD。
