# 任務系統驗證紀錄（2026-09-30）

## 結論

完整測試 323 項通過、0 失敗；TypeScript 檢查無錯誤；正式打包成功。實際瀏覽器完成任務開關、後續章節預覽、領獎、重載保存、跨日舊存檔恢復及手機尺寸檢查。

這是功能驗收，不是整體遊戲樂趣或 1–250 等長期節奏已平衡的證明。

## 本輪修正

- 任務列收合後仍維持 720px 寬，展開按鈕落入嚮導浮層底下。收合列改為最多 380px，展開面板調高層級；新增 CSS 回歸檢查，並實際點擊確認。
- 商團技能的狀態宣告改用既有六技能 `GuildSkills` 型別，避免與戰鬥、貿易、技能面板的型別不一致。此修改不改變數值規則。
- 存檔恢復的主角最大血量讀取補上可選存取，與既有缺少主角資料的恢復流程一致。

## 真實瀏覽器結果

使用獨立瀏覽器工作階段 `quest-audit` 與角色「任務測試員」，沒有修改玩家瀏覽器的存檔。為避免耗時升級，領獎與跨日測試只對此隔離角色注入測試條件；不是自然練到 Lv.10 的試玩。

| 項目 | 實測結果 |
| --- | --- |
| 展開／收合 | 修正遮擋後可實際點開 |
| 後續任務 | 切換至 241–250 等，可查看章末目標、前置與獎勵；鎖定任務不可提前領取 |
| Lv.10 成長任務 | 銀兩 +1,400，經驗 +167，與面板一致；領取後停用 |
| 每日清剿 | 銀兩 +800，經驗 +41，與面板一致；領取後停用 |
| 重新載入 | 銀兩 5,960、經驗 208；永久與每日已領取紀錄均保留，沒有重發 |
| 跨日恢復 | 將隔離存檔日期設為昨日後重開；每日日期恢復當日，計數與領獎紀錄清空，永久紀錄保留，銀兩與經驗不變 |
| 桌面尺寸 | 1262px 視窗無橫向溢出；任務與章節切換可操作 |
| 手機尺寸 | 390×844；面板 x=10、y=100、寬 370、高 650，右緣 380、底緣 750；頁面寬 390，無橫向溢出，內容需捲動 |
| 頁面錯誤 | 驗證流程沒有框架錯誤浮層，瀏覽器錯誤紀錄無輸出 |

跨日瀏覽器驗證是模擬昨日存檔的恢復，不是實際等待午夜。午夜切換的時間規則另由自動測試涵蓋。隔離瀏覽器已關閉。
