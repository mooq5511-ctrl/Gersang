# NPC 與任務設計

NPC 是城鎮導覽、任務、交易與世界觀的入口。資料位於 `data/npcs/`，對話／進度流程位於 `app/npc-dialogue.ts` 與 `app/npc-dialogue-panel.tsx`。

## 設計原則

- 使用穩定 ID：`<地點>-<角色>`，例如 `hanyang-apothecary`；顯示名稱不得當作 key。
- 任務 ID 使用 NPC 或區域前綴，例如 `hanyang-apothecary-herb-request`。
- 任務資料描述條件與獎勵；UI 只負責顯示與觸發，不在元件內硬編數值。
- 每次完成、領獎與重載都須可判定，且一次性獎勵不可重複取得。

## NPC 條目範本

```md
### 漢陽藥師
- ID：`hanyang-apothecary`
- 地點：漢陽
- 功能：藥品服務、草藥委託
- 解鎖：新角色可見
- 對話語氣：務實、關心旅人
- 進度：初遇 → 接受委託 → 交付 → 完成
- 相關資料：`data/npcs/hanyang.ts`
- 測試：對話分支、條件未滿足、領獎一次、重新整理後進度
```

### 草藥委託
- ID：`hanyang-apothecary-herb-request`
- 委託人：`hanyang-apothecary`

- 目標：
- 獎勵：
- 是否可重複：否
- 存檔欄位：

- 驗收：接取、推進、完成、重載、重複點擊。

## 實作檢查

- [ ] ID 與顯示文字分離。
- [ ] 對話在每個進度狀態均有合理文案。
- [ ] 條件不足時不扣除物品、不發放獎勵。
- [ ] 完成後可安全重新整理，且一次性獎勵不重複。
- [ ] 新增進度欄位有舊存檔預設值與測試。
