# 裝備重設第九輪：正式系列版本化與交易閉環

狀態：部分正式接入，完整方案仍未完成。沒有 push、merge、deploy；沒有重算玩家現存舊裝或寫入實際存檔。

## 正式接入範圍

- 既有十個等級、七種部位、70 個 `series-{level}-{part}` 定義使用共用 equipment-budget-policy 與 equipment-v1-policy。既有地圖掉落與 Lv.120／150／180／200 過渡商店沿用真實入口，不增加假地圖或掉落來源。
- 新生成系列裝備明確寫入 definitionId 與 balanceVersion=equipment-v1-20261004；只有已知 ID 加精確版本才使用新版。缺失／未知版本保留舊規則，不靠名稱或 UID 推測。
- 新版原始核心不預乘品質，唯一有效數值入口計算品質 1／1.2／1.5／2／2.5，強化每級 4%（+15 上限），兩者乘後取整一次。八欄參考裝備的兩枚戒指共用原配額；每枚相同定義，不額外贈送另一整份飾品預算。
- 新版強化保證成功，费用為定義基價的 10% ×下一強化等級，向上取整；+5／10／15 契印值改為 1／2／4%，目前保留攻擊／防禦／經驗三種類型等機率。舊版保底、成本、失敗規則不改。
- 新版回收價為定義基價 ×20% ×品質，強化／詞條不退款；原始核心被改動不會改變新款回收價。

## 合成正式交易

新版三件同款同品質保證升品質；普通／稀有／史詩／傳說升階每組費用為基價 ×25%／50%／100%／200%。新舊版本分組，舊版仍五件原成功率；强化或鑲嵌物品不可投入。

planEquipmentFusion 同時供介面和動作使用：先列完整組數與總費，再一次核對全額資金，資金不足退回原狀、不生成、不扣材料或銀兩。混合批次只有舊版需擲成功率；新版不擲骰。背包實際無有限容量，合成數量只會減少，沒有虛構背包滿規則。提示及日誌記錄件數、組數、費用、成功／失敗。

工坊預覽與合成成功提示改用 effectiveEquipmentStats，避免新款稀有裝原始數值未變而顯示「沒有提升」。里程碑預覽傳入實際版本。商店系列區另外說明新版倍率，舊商品的 ×150 不適用新版。選取是預覽，一鍵合成仍是全背包，文字與確認視窗明示範圍。

依 React 介面檢查指引，候選 UID 用 Map 查找，合成費用／可選物品直接由當前 props 推導，不增加同步 effect 或重複狀態。這不是瀏覽器效能測量或卡頓已修好之證據。

## 驗證

- equipment-v1-runtime.test.mjs 新增七項：250級設計預算一致、70種核心在金色+15與八欄候選一致、三件保证／精確费用／輸入不變、資金不足／强化／鑲嵌保護、新舊同名分組與舊失败損失、+15全程費用／品質一次／回收／存讀檔、實際商店購買、穿戴武器／ring2與未知版本相容。
- 商店舊測試改成同時驗證未乘品質原始核心與有效品質數值；鑑定機率、城市價格、每件唯一 UID、等級限制仍驗證。兩檔 14/14 通過。
- 世界怪物參考隊伍「更好裝備」改走實際品質提升，不再直接乘原始核心（新版本忽略這種直接改值）。節奏測試維持原上下界，收集全部不合格項而非第一項停止。
- 全套 499 項，495 通過、4 失敗。3 項是此前已有的不可變 AST 模組快照，沒有覆寫基準；第4項為新版裝備造成的實際節奏失敗，不能宣稱全綠。
- 節奏不合格：e_sumeru_training_thunder_beast／e_yeti／e_taj_scarab／e_ghost 入口怪皆3.95秒（目標5～8.5秒）；e_snake主力怪7.85秒（目標8～15秒）。這是固定滿階四人參考隊與技能的測試，不是自然新角色遊玩。
- TypeScript 檢查成功；新版政策／合成／數值／動作／工坊等定向 lint 成功。城市頁加入檢查後仍有六項既有 next/no-img-element 錯誤；本輪城市頁 diff 僅修改系列說明，未新增圖片，沒有用關掉規則掩蓋。
- 最新完整 build 成功，仍有 >500KB chunk、插件耗時及路由靜態分類警告，未進行本輪瀏覽器驗證。

## 尚未完成的完整目標

其他普通／官方／附魔／遺跡／神裝來源尚未全數版本化；特殊數值共有預算、寶石上限／定價、經驗契印平均及25%上限仍需正式接入。舊裝轉換預覽尚沒有實際備份／確認／套用／回復介面。恢復模型仍是候選。五隻過快怪物的數值銜接須校準。自然新角前30分鐘、真實取得成本、離線／自動探索、瀏覽器與正式版效能仍待驗證。

歷史測量腳本的 `current` 參數目前明確指 pre-V1 frozen baseline，使用 makeLegacyTierEquipment，不再代表今天的新款生成器。不要把前八輪離線比較當成新版正式版實测完成。
